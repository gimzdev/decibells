# Decibells

Distributed verification network with token incentives.

[Docs](https://docs.decibells.network) · Node.js · IPFS · GraphQL

</div>


A general-purpose verification network: when a piece of data matters, several validators agree on
what it says, and the agreement can be proven afterwards.

- **Network**: libp2p with Byzantine fault tolerance
- **Records**: kept on IPFS, the rules in smart contracts
- **Incentives**: validators earn tokens for the audit work and lose stake when they are wrong

`Submit → Validate → Consensus → Record → Reward`. For supply chains, documents, voting and research data.
